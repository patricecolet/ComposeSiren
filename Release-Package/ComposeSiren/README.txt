ComposeSiren v1.5.0
===================

Merci d'avoir téléchargé ComposeSiren !

INSTALLATION
============

Ce package contient trois formats de plugin :

1. ComposeSiren.vst3 (VST3)
   Installation : Copier dans ~/Library/Audio/Plug-Ins/VST3/

2. ComposeSiren.component (Audio Unit)
   Installation : Copier dans ~/Library/Audio/Plug-Ins/Components/

3. ComposeSiren.app (Application Standalone)
   Installation : Copier dans /Applications/ ou lancer directement

COMPATIBILITÉ
=============

- macOS 10.13 ou supérieur
- Compatible Intel (x86_64) et Apple Silicon (ARM64)
- DAWs supportés : Logic Pro, Ableton Live, Pro Tools, Reaper, etc.

UTILISATION
===========

Après installation, relancez votre DAW. ComposeSiren apparaîtra dans :
- Logic Pro : Instruments > AU Instruments > Mecanique Vivante
- Ableton Live : Instruments > VST3 > Mecanique Vivante
- Autres DAWs : Catégorie Instruments/Synth
