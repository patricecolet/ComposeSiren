DESCRIPTION
===========

ComposeSiren is a professional audio plugin suite for music production.

SYSTEM REQUIREMENTS
===================
- macOS 10.15 (Catalina) or later
- Intel (x86_64) or Apple Silicon (arm64)
- Universal binary (supports both architectures)

INSTALLATION
============
The installer will install:
- Standalone applications in /Applications/Mecanique Vivante/
- Audio Unit (AU) plugins in /Library/Audio/Plug-ins/Components/
- VST3 plugins in /Library/Audio/Plug-ins/VST3/
- Resources in /Library/Audio/Plug-ins/Mecanique Vivante/

UNINSTALLATION
==============
Use the "UninstallComposeSiren_Orchestra.app" application included in this DMG
to remove all installed components.
